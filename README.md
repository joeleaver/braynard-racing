# Braynard Racing

An open-world kart racer starring barnyard animals, built on the [Playweft](https://github.com/joeleaver/playweft)
engine. It's Playweft's flagship game.

This repo holds the game project ([`game/`](./game), with how to open and play it in its README), the art in
progress ([`art/`](./art)), the audio ([`audio/`](./audio)) and the tools that build the karts and props
([`tools/`](./tools)). The design and the plan are kept outside the repo.
